الدليل الطبي — نسخة جاهزة للبناء بواسطة GitHub Actions

هذه الحزمة معدة بحيث يقوم GitHub ببناء ملف APK تلقائياً بدون الحاجة إلى تثبيت Java أو Android Studio على جهازك.

الخطوات:
1) فك ضغط الملف.
2) افتح github.com وسجّل الدخول إلى حسابك.
3) أنشئ مستودعاً جديداً (Repository).
4) ارفع جميع ملفات ومجلدات المشروع إلى المستودع، بحيث يظهر مجلد .github في جذر المشروع.
5) افتح تبويب Actions.
6) اختر: Build Android APK.
7) اضغط Run workflow.
8) انتظر حتى تصبح العملية باللون الأخضر.
9) افتح نتيجة التشغيل، ثم قسم Artifacts، وحمّل ملف: الدليل-الطبي-APK.
10) فك الضغط عن Artifact وستجد app-debug.apk جاهزاً للتثبيت على هاتف Android.

مهم:
- لا تحذف مجلد app أو مجلد .github.
- لا تغيّر اسم مجلد .github أو ملف build-apk.yml.
- هذه النسخة تستخدم Android API 35 وAndroid Gradle Plugin 8.7.3 وGradle 8.9.
- لا توجد مفاتيح توقيع أو كلمات مرور سرية داخل المشروع. ملف APK الناتج هو Debug APK مناسب للتجربة والتثبيت المباشر.
- عند الحاجة إلى نسخة Release موقعة لاحقاً، يمكن إضافتها بأمان باستخدام GitHub Secrets دون وضع كلمة المرور داخل المشروع.


=== تحديث التطبيق من الخادم ===
لوضع حزمة تحديث على خادم الشبكة، ضع الملف app-update.apk داخل مجلد الخادم نفسه، وأنشئ ملفًا باسم update.json مثل:
{"available":true,"versionCode":3,"versionName":"1.2"}
عند الضغط على «البحث عن التحديثات» سيقارن التطبيق versionCode المثبت مع النسخة الموجودة على الخادم، وإذا كانت أحدث يعرض للمستخدم تنزيلها وتثبيتها.
ملاحظة: قد يطلب Android السماح بتثبيت التطبيقات من هذا المصدر في إعدادات الجهاز عند أول تحديث.


=== نظام التحديث عن بُعد ===

1) تحديث واجهة HTML/CSS لا يحتاج إعادة بناء APK. ضع الملفات داخل مجلد الخادم: updates/الدليل_الطبي.html و updates/bootstrap.min.css.
2) عدّل update.json في مجلد الخادم، مثال:
{
  "htmlVersion": 2,
  "cssVersion": 2,
  "apkVersionCode": 0,
  "apkVersionName": "",
  "htmlUrl": "/updates/الدليل_الطبي.html",
  "cssUrl": "/updates/bootstrap.min.css",
  "apkUrl": "/updates/app-update.apk"
}
3) تحديث Kotlin/Android يحتاج APK جديدًا، يوضع في updates/app-update.apk مع زيادة apkVersionCode.
4) عند الضغط على البحث عن التحديثات يقارن التطبيق نسخة HTML ونسخة APK بشكل مستقل.
5) أي جهاز لا يملك ملفات التحديث يبقى على النسخة المضمنة داخله.


## رفع التحديثات من داخل التطبيق (للمدير)
بعد تسجيل الدخول بحساب المدير، افتح الإعدادات ثم «المزيد». تحت «البحث عن التحديثات» تظهر لوحة «رفع تحديثات الخادم».
- رفع تحديث الصفحة: اختر `الدليل_الطبي.html`.
- رفع تحديث التنسيق: اختر `bootstrap.min.css`.
- رفع تحديث التطبيق: اختر ملف APK الذي بنيته.
لا تحتاج إلى تغيير أسماء الملفات. الخادم يستبدل الملف السابق بنفس الاسم ويزيد رقم الإصدار تلقائيًا، ثم يظهر الإصدار الجديد في فحص التحديثات.
يجب أن يكون تطبيق المدير متصلًا بالخادم، وأن يكون الخادم الذي يشغّل `lan_server_android_cors.py` هو الخادم المقصود للتحديث.
